# Для Варвары ♡

Нежный одностраничный сайт-признание: скрапбук, поляроиды, письмо, пожелания и конверт с главным сообщением.

## Главное

Теперь это **один файл** — `index.html`. Внутри него уже есть всё:

- стили;
- скрипты и анимации;
- шрифты;
- все четыре гифки (в лёгком формате WebP);
- иконка сайта.

Никаких папок `assets`, `css`, `js` и внешних ссылок нет. Поэтому сайт не может «сломаться» из-за потерянной папки.

## Как проверить локально

Просто открой `index.html` двойным кликом в браузере. Интернет не нужен — всё работает офлайн.

## Как выложить на GitHub Pages

1. Создай новый репозиторий, например `dlya-varvary`.
2. Загрузи в него **только `index.html`** (можно перетащить файл прямо в окно GitHub).
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Укажи ветку `main` и папку `/ (root)`, нажми **Save**.
6. Через минуту сайт будет здесь:
   `https://<твой-логин>.github.io/dlya-varvary/`

### Через терминал

```bash
git init
git add index.html
git commit -m "для Варвары"
git branch -M main
git remote add origin https://github.com/<логин>/dlya-varvary.git
git push -u origin main
```

Потом в **Settings → Pages** выбрать ветку `main` и папку `/ (root)`.

> В проекте есть `.gitignore`: он не даст случайно загрузить исходные гифки на 13 МБ и папку `assets`, которая нужна только для сборки.

## Что внутри `index.html`

- Hero с именем, поляроидами и бегущей строкой.
- «За что я тебя люблю» — 6 причин.
- «Три вещи, в которых ты лучшая»: умная, красивая, милая.
- Письмо «Как ты мне дорога».
- Счётчик любви: после нескольких нажатий показывает `∞`.
- Пожелания.
- Конверт в финале: открывается по нажатию, внутри главные слова.
- Секретная записка в блоке письма.

## Что можно поменять

- Все тексты — прямо в `index.html`. Ищи фразы через поиск в редакторе (файл большой из-за встроенных картинок, GitHub в браузере может открывать его медленно — лучше VS Code или Notepad++).
- Цвета — в начале блока `<style>`, переменные `--cream`, `--pink`, `--berry` и другие.
- Финальное письмо и подписи — в конце файла, в секции `finale`.

## Мелочи

- Открывается на телефоне: всё в одну колонку, кнопки удобные для пальца.
- Есть `prefers-reduced-motion`: если у человека отключены анимации, сайт остаётся читаемым.
- Текст и письмо видны даже без JavaScript, просто без эффектов.
- Превью для мессенджеров отдельной картинкой не сделано — чтобы остался ровно один файл. Если оно нужно, можно добавить `og-image.png` рядом и прописать полный URL в `og:image`.
